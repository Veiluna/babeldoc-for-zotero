## 3. 尚未完成 / 下一步任务

### 3.1 0.7.0 主功能：分栏双语排版（用户需求，尚未开始实现）
用户原始需求（需先 spec 化并交用户审批）：
1. 分栏双语排版：若源 PDF 分栏（一页两栏），输出改为"左右对照"——**每个输出页左半=英文、右半=中文**；源双栏页拆成 2 个输出页（每栏各一页，页数约为原 PDF 两倍）；单栏页输出 1 页（左英右中）。
2. 跨栏元素（标题/作者/摘要/图片/表格/公式）**只保留译文版本**，横跨输出页替换（无英文侧留白、不重复）；英文对照仅存在于非跨栏的栏内正文。
3. 划词行为：从英文侧开始选择只选英文、从中文侧开始只选中文、跨页保持；划词若涵盖跨栏元素则忽略，单独划跨栏元素才可选中。
4. 链接/引用/页码按页数翻倍重映射。
- 计划流程：先 /research（Zotero 10.0.6 阅读器选择 API + PDF 文本层结构）+ /prototype 验证划词与版式；再 /to-spec（spec+ADR）→ /to-tickets（GitHub issues）→ 用户审批 tickets 拆分 → /tdd 实现（teammate）→ 每轮新开 2 个审查者 → 真实门禁（P01+T01）→ 发布。
- 已知约束：Zotero 选择 API 可能无法完全阻止跨语言混选，用户已同意"API 允许范围内尽量 + spec 写明限制"。
- 单栏页默认 1 页；跨栏元素默认放对应输出页（需在 spec 定稿）。
