## 规则摘要（2026-10-30 修订）

- **全文只分单栏、双栏**：`detect_document_columns` 有 ColumnCount 标签（1 或 2）时直接用（basis=tag）；否则从第 1 页往后找第一页回跳点，回跳前后两组文字分在页面中线两侧即双栏（basis=jump，page=该页）；找不到为单栏（basis=single）。
- **回跳点**：按书写顺序相邻的两条书写行，后一行基线高过前一行顶部（`next.baseline < prev.y0`），且回到本组第一行或更高（`next.baseline <= 本组首行 baseline`），且起点在前一行终点右边（`next.x0 > prev.x1`）。页眉页脚行（margins）与 YOLO 图、表、公式范围内的书写行不参与。上标、行内上下标与所在行同属一条书写行；分式分子、首字下沉不触发。
- **压中线归栏（双栏文档的每一页）**：中线 `mid = width / 2`。按 `build_rows` 得到的视觉行，行内任一字符框满足 `x0 < mid < x1` 即整行跨栏（SPANNING）；否则字符按 `x1 <= mid` 归左栏、`x0 >= mid` 归右栏。YOLO 图表公式范围压中线即跨栏元素，范围内的行随元素跨栏。段落里有字在跨栏行上即整段跨栏；字符同时在左右两侧且不含跨栏行的段落列入 `split_paragraphs`。整页全部是跨栏行的页照跨栏输出。单栏文档每页 `columns=1`。
- **line_column 的含义**：每条书写行一个值，仅作日志与调试摘要；同一书写行的字分在中线两侧、但无字压中线时取首字所在一侧。段落归栏与变体取字一律按每个字自己的位置，依赖 build_lines 产物（2026-10-30 用户确认）。
- **已知限制**：IL 字符没有真实文字基线，基线用字框底边近似；行首为上标等少见写法可能分错书写行（见 issue）。
- **页眉页脚**：不变（标签 → 跨页重复 → 追加内容流辅证；不以字体为规则）。margins 中的行标 MARGIN，不参与认栏；所在段落若全部为 MARGIN 行，该段不进任何变体。
- 废止：半页高门槛、同基线空隙交集备用依据、按字间空隙切行、N 栏推广。不引入任何视觉坐标容差；不以字体为规则。
