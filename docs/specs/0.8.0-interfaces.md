## 规则摘要（详见规格"认栏"一节）

- **切行**：按 (order, sub_order) 遍历字符；同一基线连续写出的字符归为一行。基线判定只用字符自身坐标数据（如 y1 相同或字符框纵向重叠），不得引入"按经验放宽 n pt"的视觉容差常量。
- **回跳点**：相邻两行中后一行 y 回到前一行上方超过半页高，且起始 x 位于前一行结束 x 之右。
- **栏缝**：左组最大结束 x 到右组最小起始 x，> 0 即两栏。否则用备用依据：同基线两段文字之间的空隙在多数行里落在同一 x 区间，取交集。两者都不成立就是一栏。N 栏同理推广。
- **跨栏行**：栏缝区间内有字符，或起止 x 跨过栏缝且中间没有栏缝宽的空隙。含跨栏行的段落为跨栏段落。
- **段落归属**：字符全在第 k 组 → k；含跨栏行 → SPANNING；左右组混合 → 记入 `split_paragraphs`。
- **页眉页脚**：标签 → 跨页重复（数字替换为同一占位符后，≥1/3 页以相同基线 y 出现）→ 追加内容流只用来印证，不单独判定。不以字体为规则。
- 不引入任何视觉坐标容差；不以字体为规则。
