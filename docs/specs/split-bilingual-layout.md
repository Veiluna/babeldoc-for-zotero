# 分栏双语排版规格（0.7.0）

> 状态：草案，待用户审批。调研与真机验证见 [docs/research/split-bilingual-layout.md](../research/split-bilingual-layout.md)，决策记录见 [ADR 0008](../adr/0008-split-column-bilingual-layout.md)。

## 背景

现在的"双语对照 PDF"直接用 BabelDOC 的整页并排：每页左边整页原文、右边整页译文。双栏论文在这种版式里，一栏英文要对照的中文在半个屏幕以外，阅读时视线来回跳；划词也会把两种语言混在一起选中。

用户要求把双语改成按栏对照：每个输出页左半英文、右半中文；源 PDF 的双栏页拆成两个输出页（每栏一页），单栏页输出一页；标题、作者、摘要、图、表、公式这类跨栏元素只保留译文、横跨整页；划词时英文侧只选英文、中文侧只选中文，跨页保持；链接、引用和页码随新页面重新对应。

## 目标

1. 右键菜单"生成双语对照 PDF"产出**分栏双语 PDF**，取代整页并排版式。
2. 版式：
   - 每个输出页分左右两侧，左侧是某一栏的原文，右侧是同一栏框内的译文，两侧纵向位置与源页一致，字号不缩放。
   - 源双栏页拆成两个输出页：A 页对应左栏，B 页对应右栏。单栏页输出一页。
   - 输出页高度与源页相同；宽度取"源页宽"与"两倍栏宽加边距"中的较大者。双栏论文通常保持原宽，单栏页会变宽。
3. 跨栏元素：横跨两栏的内容（标题、作者行、跨栏摘要、跨栏图表、跨栏公式等）只放译文版本，横跨整个输出页宽度，不在英文侧留白、不重复。
   - 位于两栏正文上方的放在 A 页顶部；位于两栏正文下方的放在 B 页底部；位于页面中部的放在 A 页原纵向位置，B 页在同一位置收拢空白。
4. 页眉、页脚、页码：只保留原文一份，按源页位置横跨整页；A、B 两页都显示。
5. 划词（Zotero 10.0.6 阅读器内）：
   - 从英文侧开始拖选只选中英文侧文字，从中文侧开始只选中中文侧文字，跨页保持同一侧。
   - 选区经过跨栏元素时忽略它；只有从跨栏元素内开始拖选才能选中它，且只选中跨栏元素。
   - Zotero 原有的页眉页脚隔离行为保持不变。
6. 链接与目录：
   - 英文侧的链接按原文 PDF 的链接重建，内部跳转落到目标位置所在输出页的英文侧；中文侧按译文 PDF 已恢复的链接重建，跳转落到中文侧（跨栏元素只有译文，落到跨栏元素本身）。外部链接照常可点。
   - 目录（大纲）条目指向对应位置所在的输出页。
   - PDF 页码标签：单栏页沿用源页码（如 `41`），双栏页的 A、B 页分别为 `41a`、`41b`；源 PDF 没有页码标签时用源页序号。
7. 不增加任何模型请求，也不新增用户设置项。

## 非目标

- 不改单语中文 PDF 的行为和产物。
- 不处理三栏及以上的版式、旋转页、扫描页的按栏拆分，这些页回退为"整页并排"（见"回退"）。
- 不追求中英段落逐段水平对齐；中文侧按 BabelDOC 排版位置原样放置，留白不重排。
- 不修改 Zotero 本身，不保证其他 PDF 阅读器里的划词隔离。
- 不恢复表格翻译（仍按 ADR 0007 封存）。

## 详细设计

### 流程

```
源 PDF ──BabelDOC（--no-dual）──> 单语中文 PDF + 版面 JSON
                                    │
源 PDF + 单语中文 PDF + 版面 JSON ──分栏规划──> 页面计划
                                    │
                              ──分栏合成──> 分栏双语 PDF（含版面元数据、链接、目录、页码标签）
                                    │
                         Zotero 导入译本附件；打开时阅读器钩子读取版面元数据
```

### 1. 版面 JSON（runner 导出，Lead 接线）

BabelDOC 排版完成后，runner 从 IL 页对象导出每页版面，写在工作目录 `layout.json`：

```json
{
  "version": 1,
  "pages": [
    {
      "index": 0, "width": 612, "height": 792,
      "paragraphs": [{"box": [x0, y0, x1, y1], "label": "text", "translated": true}],
      "layouts":    [{"box": [x0, y0, x1, y1], "class": "figure"}]
    }
  ]
}
```

坐标统一为左上原点、单位 pt（与 PyMuPDF 一致）。`translated=false` 的段落即保留段落（页眉页脚、页码等）。

### 2. 分栏规划（新模块 `ztf_split_plan.py`）

输入：一页版面。输出：页面计划（冻结接口，见"冻结接口"）。规则：

1. 正文段落（版面标签属于正文类）按 x 聚类成 1 或 2 栏；得到栏框与栏间隙（gutter）。聚出 3 栏及以上，或页面旋转，或没有正文段落时，整页标为回退。
2. 页眉、页脚：保留段落中，位于全部正文段落上方或下方、且不在任何栏框内的，归为页眉页脚带。
3. 跨栏带：在两栏页中，任何元素（段落或版面框）与栏间隙在水平方向相交，就把它所在的纵向区间标为跨栏带；相邻或重叠的跨栏带合并。作者行这种由几个窄块组成的行，只要其中一块跨过栏间隙，整行即为跨栏带。
4. 跨栏带按位置分类：上方（在两栏正文最上缘之上）、下方（在两栏正文最下缘之下）、中部（其余）。
5. 单栏页：没有跨栏带，整个正文框作为唯一一栏。

### 3. 分栏合成（新模块 `ztf_split_compose.py`）

1. 对每个计划中的区域，先复制该页到临时文档，用涂黑删除区域框外的**文字**（不动图片和矢量），再用 `show_pdf_page(clip=区域框)` 嵌入，避免栏外文字进入文本层。区域框要按单语 PDF 中与之相交的文字块向外扩展，防止译文比原文高时被截掉。
2. 输出页布局：页眉页脚带（取源 PDF）按原位置横跨整页；跨栏带（取单语中文 PDF）按 D5 放置并横跨整页居中；每栏的原文放左半、同栏框的译文放右半，左右对称放在中线两侧。
3. 内容流顺序固定为：页眉页脚 → 跨栏带 → 英文侧 → 中文侧。这样即使阅读器钩子失效，页内同侧拖选也保持连续。
4. 页宽：`max(源页宽, 2 × 栏框宽 + 3 × 12pt)`；栏间隙至少 12pt。
5. 回退页：输出一页，宽度为两倍源页宽，左边整页原文、右边整页译文（即现在的整页并排），在版面元数据中标 `fallback`。
6. 在输出 PDF 中写入版面元数据（见"冻结接口"），供阅读器钩子使用。

### 4. 链接、目录、页码标签（`ztf_split_compose.py` 内的独立函数）

- 建立"源页 + 点 → 输出页 + 点"的映射，按侧（英文、中文）分别建。跨栏带内的点只有中文侧映射。
- 英文侧链接取自源 PDF，中文侧链接取自单语中文 PDF（已经过 `ztf_links` 恢复）；链接框只保留落在对应区域内的部分并按嵌入变换平移。
- 内部跳转目标按映射换算；目标落在页眉页脚带或映射不到时，跳到对应输出页顶部。
- 目录取源 PDF 大纲，每条目标按英文侧映射换算；源 PDF 没有大纲时保持没有。
- 页码标签按 D6 设置。

### 5. 阅读器划词钩子（新 JS 模块 `readerSelection.js`）

- 在 Zotero 打开 PDF 阅读器标签页时检查附件是否为分栏双语 PDF（读版面元数据）；不是则什么都不做。
- 是则在阅读器视图的 iframe 窗口上注册捕获阶段 `pointerdown` 监听：按起点坐标判定区域类别（英文侧、中文侧、跨栏、Zotero 页眉页脚隔离区），把所有已加载页字符的 `isolated` 设为"类别不同于起点"；Zotero 原有隔离字符单独成一类。
- 之后加载的页面也要按当前起点类别补设标记（包装视图的页面数据合并入口）。
- 分屏阅读时两个视图都要挂钩。
- 任何一步取不到预期的内部对象或方法时，记录一次诊断日志并放弃挂钩，回退到内容流行为；不得抛错影响阅读器。
- 调用阅读器方法时传入的对象需克隆到阅读器窗口（真机验证中遇到过 "Permission denied"）。

### 6. 菜单、导入与文案

- 菜单"生成双语对照 PDF"文案不变，产物改为分栏双语 PDF；附件文件名后缀仍为 `.zh.dual.pdf`。
- 合成整体失败时，按现有降级逻辑导入单语中文 PDF，并在完成提示中说明"未能生成分栏双语 PDF，已导入单语中文译本"。
- GLOSSARY"双语对照 PDF"词条改为分栏双语定义；README 更新截图与说明。

## 冻结接口

### 页面计划（`ztf_split_plan.plan_page` 返回值）

```python
@dataclass(frozen=True)
class Region:
    kind: Literal["header_footer", "spanning", "column", "fallback"]
    box: tuple[float, float, float, float]   # 源页坐标，左上原点
    position: Literal["top", "middle", "bottom", "none"] = "none"  # 仅 spanning 使用
    column: int = -1                         # column 区域的栏序号，从 0 开始

@dataclass(frozen=True)
class PagePlan:
    source_index: int
    columns: int            # 0 表示回退页
    regions: tuple[Region, ...]
```

### 版面元数据（写入输出 PDF）

写入文档信息字典自定义键 `ZTFSplitLayout`，值为紧凑 JSON：

```json
{"v": 1, "pages": [{"src": 0, "part": "a", "regions": [{"k": "en|zh|span|hf", "r": [x0, y0, x1, y1]}]}]}
```

`r` 为输出页 PDF 用户空间坐标（左下原点），便于与 Zotero 字符坐标直接比较。实现前须核实 pdf.js `getMetadata()` 能读出该自定义键；读不出时改用 XMP 元数据，接口字段不变。

## 风险

- 钩子依赖 Zotero 阅读器的非公开结构（`_primaryView`、`_pdfPages`、字符 `isolated` 标记），Zotero 升级可能失效；失效时自动回退，并在 README 写明。
- Zotero 的引用识别会同时看到中英两份参考文献，引用跳转可能识别出重复条目（未核实）。
- BabelDOC 版面标签对作者行、页中跨栏图的识别质量决定跨栏判定质量，需在 P01、T01 上人工核对。
- 单栏页加宽后，Zotero 默认"适应宽度"缩放会使文字变小，用户需要手动放大。
