# ADR 0007：0.7.0 暂缓表格翻译（仅翻译题注；表注与表格内容保留原文）

## 背景

0.6.0 发布后的表 2 问题（部分翻译、字号缩小）修复（issues #37/#38）在 0.7.0 T-B3 中经历多轮独立双轴审查仍未收敛：同格多段落字号不一致导致文字叠印、无线表几何判定退化、错误文本脱敏、正文回归断言无效、测试假绿等。用户决定：当前版本不再处理表格内容，仅翻译题注（表注/星号说明/来源注释与表格内容一并保留原文），表格翻译问题留待后续版本。表注翻译因碎片合并链路在保留原文路径存在 P1 缺陷（runner 失败/丢字），按硬收敛线回退为保留原文。

## 决策

1. **0.7.0 起表格内容完全不翻译**：表头、表体、旋转表头等表内单元格一律保留原文；不发表格补译请求；不做表格字号 patch。
2. **翻译范围**：表格题注（如 "Table 2: Daily Label of Dataset."）、表外正文引用（如 "Table 2 shows ..."）与图内文字（含图内小表格/表头）照常翻译；表内单元格与表注/表外附注（星号说明、来源注释）保留原文。
3. **封存表格处理代码**：ztf_table_text.py、ztf_table_headers.py、ztf_table2.py、ztf_table_layout.py **移动到 addon/content/python/archive/**（不删除），顶部标注"封存"；其中 3 个曾部署（text/headers/table2）从 runner.js 清单移除，table_layout 新增后未接线即封存；runner 不再加载；相关接线禁用；封存模块单测从 archive/ 导入。build-xpi.ps1 已排除 archive/，封存代码不随插件发布。
4. **文档与问题清单**：docs/archive/table-translation.md 记录功能说明、封存清单、已知问题与恢复步骤。
5. **测试与质量夹具**：封存模块的契约单测保留（直接 import）；生产行为测试改为"表格内容保留原文 + 题注翻译"；T01 质量夹具的表格检查同步调整。

## 后果

- 0.6.0 的表格翻译行为（表头/表体/旋转表头/表2 补译）在 0.7.0 移除；README、spec、GLOSSARY 需同步。
- 表格相关请求（表2 补译）不再产生，单篇请求数下降。
- issues #37（表体规则）与 #38（字号 patch）标记为暂缓/封存，待后续版本恢复时参考 docs/archive/table-translation.md。
- 发布门禁：P01 + T01 真实重跑需验证"表格内容与表注保留原文、题注翻译、图内文字翻译、表外正文翻译"。
