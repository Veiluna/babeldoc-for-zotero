# 改名 BabelDOC for Zotero，并更换插件 ID 和偏好前缀

原名 Translate Files for Zotero 与已有插件 Translate for Zotero 过于接近。公开发布前一次改干净：显示名 BabelDOC for Zotero，仓库 `babeldoc-for-zotero`，插件 ID `babeldoc-for-zotero@veiluna.github.io`，偏好前缀 `extensions.babeldoc-for-zotero.`。新 ID 意味着 Zotero 视其为新插件，因此首次启动时从旧前缀 `extensions.zotero-translate-files.` 迁移设置，旧插件由用户手动卸载。
