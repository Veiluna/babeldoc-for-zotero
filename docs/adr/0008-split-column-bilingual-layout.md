# ADR 0008：双语对照改为分栏双语，划词隔离借用 Zotero 阅读器的隔离字符机制

## 背景

0.6.0 的"双语对照 PDF"直接使用 BabelDOC 的整页并排输出。用户要求改为按栏对照（左英右中、双栏页拆成两页、跨栏元素只留译文），并要求划词按语言隔离。BabelDOC 0.6.4 的双语输出只有整页并排和隔页交替两种，没有按栏模式（context7 `/funstory-ai/babeldoc`）。

调研（docs/research/split-bilingual-layout.md）确认：

- BabelDOC 单语中文 PDF 与原文页面尺寸和栏位一致，可以按栏裁切对位；
- Zotero 10.0.6 阅读器按 PDF 内容流顺序组织字符，只靠 PDF 结构做不到跨页、跨侧的划词隔离；
- 阅读器自带"隔离字符"过滤（`applySelectionRangeIsolation`），插件在按下鼠标时改写字符的 `isolated` 标记即可实现按区域隔离，真机五条用例全部通过。

## 决策

1. 双语菜单项的产物改为分栏双语 PDF，不再提供整页并排；BabelDOC 只生成单语中文 PDF，分栏双语由插件用 PyMuPDF 合成。
2. 合成时先涂黑删除区域外文字再按区域嵌入，内容流顺序固定为页眉页脚 → 跨栏 → 英文 → 中文。
3. 栏太宽时加宽输出页，不缩小字号；页眉页脚页码只保留原文一份。
4. 划词隔离由插件钩子在 Zotero 阅读器中改写字符 `isolated` 标记实现；钩子取不到内部对象时放弃并回退到内容流行为，不影响阅读器其他功能。
5. 三栏及以上、旋转页、扫描页等无法规划的页面回退为整页并排；整篇合成失败时降级导入单语中文 PDF。

## 后果

- 双语产物的页数约为原文两倍（双栏论文），单栏页变宽。
- 划词隔离依赖 Zotero 非公开结构，每次 Zotero 大版本升级需复测；README 写明这一限制。
- BabelDOC 不再生成整页并排的双语 PDF，双语模式的 BabelDOC 渲染时间略减。
- GLOSSARY"双语对照 PDF"定义、README、质量检查脚本需同步更新。

## 备选方案

- **只靠 PDF 内容流顺序**：不碰 Zotero 内部，最稳；但跨页、跨侧拖选会混入另一种语言，不满足用户要求。保留为钩子失效时的回退行为。
- **用 BabelDOC 整页并排输出后再裁切**：并排页的左右两半仍需按栏拆分，不比直接用单语 PDF 合成简单，还多一次渲染。
