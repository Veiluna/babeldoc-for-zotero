# ADR 0009：认栏只用 PDF 底层数据，中文按段落归属分栏排版

部分取代 ADR 0008 的决策 2、决策 3 中的加宽规则和决策 5。

## 背景

0.7.0 的分栏双语在三份实测样本上都出了问题（诊断见 0.8.0 规格"背景"一节）：

- Chen 2026：第 10、18 页左栏中文伸进栏缝 1~2pt，被判成两栏文字重叠，整篇降级成单语中文。
- FoBa：DocLayout-YOLO 画的右栏框圈进了 IEEE 下载水印，水印碎成 17 块正文段落，第 17、19 页整页并排；第 1 页中文放不下。
- 跨页、跨栏断句组两次翻译都失败，整段保留英文。

根因有两类：认栏依赖视觉模型画的框；切分中文依赖从整页译文上按坐标裁剪涂黑。放宽坐标容差只会把错误换成另一种（Chen 放宽后变成 redaction_text_mismatch）。

## 决策

1. **认栏只读 PDF 底层数据**：BabelDOC IL 里的字符坐标与内容流书写顺序，以及 PyMuPDF 读到的内容流信息。主依据是内容流回跳点，备用依据是同基线空隙的交集。YOLO 只用来给图、表、公式的范围。不引入任何视觉坐标容差，不以字体作规则。
2. **每页只有两种结果**：两栏或一栏（三栏及以上推广为 N 栏，每栏一张输出页）。不再有"认不出分栏 → 整页并排"。
3. **页眉、页脚、水印**由底层数据判定：PDF 标签 → 跨页重复（数字归一，至少 1/3 页同基线）→ 独立追加内容流仅作辅证。判定后原样保留、不翻译。
4. **中文按段落归属分栏排版**：BabelDOC 排版完成、写 PDF 之前，按段落归属对每个两栏页输出各栏和跨栏的中文排版变体，合成时整份嵌入，不再裁剪涂黑。放不下就加高该输出页，宽度和字号不变。
5. **一栏页**输出原文整页 + 中文整页两张原大小的页。
6. **单页安全网**：某页合成时出现程序异常，只有这一页按一栏页输出并记日志，整篇不再降级成单语。它只防程序错误，不是认栏失败的处理办法。
7. **断句组失败**：补译后仍失败的组拆成片段，合并为 1 次请求单独再译，计入请求上限。

## 后果

- 认栏结果可从日志（页号 + 依据 + 原因码）直接解释，不必复现。
- 需要改动 BabelDOC 排版后的流程（在写 PDF 前复制 IL 页），对 BabelDOC 0.6.4 内部结构有依赖，升级时需复测。
- 加高页会让输出页尺寸不一致，ZTFSplitLayout 版面标记要写入实际尺寸。
- 按行交替写左右栏的 PDF（如部分 Word 导出）没有回跳点，只能靠备用依据，需要样本验证。
- ADR 0008 的划词隔离（决策 4）、不缩小字号和页眉页脚只保留原文一份（决策 3）仍然有效；决策 2（涂黑裁剪）、决策 3 的加宽输出页（改为放不下就加高，宽度不变）与决策 5（整页并排回退、整篇降级）被本 ADR 取代。

## 备选方案

- **放宽 YOLO 框或坐标容差**：试过，只是把一种失败换成另一种，且用户明确不接受视觉启发式。
- **按字体区分水印**：FoBa 水印用 Helvetica、正文用 Times，但字体不能推广到其他期刊，用户明确不以字体作规则。
